Tools we maintain

Libraries and tools we build for internal use and release publicly. If it solves a problem for us, it probably solves it for someone else.

flux-core

2.4k stars
TypeScript

Durable workflow engine with typed activities, compensation chains, and an operator dashboard. Temporal-inspired, lighter weight.

v2.4.0 MIT License

audit-log

890 stars
Go

Immutable audit logging with structured events, forward-only schema migrations, and built-in compliance exports for SOC 2 and GDPR.

v1.0.0 Apache 2.0

serde-stream

1.1k stars
Rust

Streaming serialization with schema registry integration. Supports Avro, Protobuf, and JSON Schema validation at the wire level.

v1.2.0 MIT License

eval-harness

640 stars
Python

LLM evaluation framework with golden ticket sets, regression detection, cost tracking, and automated weekly reports.

v3.0.0 MIT License

conn-sdk

420 stars
TypeScript

Typed connector SDK for building integration adapters. Idempotent by default, with built-in retry and dead-letter support.

v1.1.0 MIT License

helm-bundler

310 stars
Go

CLI tool for bundling multiple Helm charts into a single deployment with dependency resolution and version locking.

v0.9.0 Apache 2.0
